- **分层架构**：采用 Monorepo (pnpm) 结构，分为 `@scribe/shared`（类型定义与协议）、`@scribe/server`（Node.js 后端）和 `@scribe/client`（React 前端）。
- **后端核心**：基于 Hono 框架提供 RESTful API 与 SSE 流式响应；使用 better-sqlite3 管理书籍元数据与对话历史，章节正文以 Markdown 文件形式存储于文件系统。
- **AI 编排层**：位于 `packages/server/src/ai/orchestrator`，负责意图分类 (`intent.ts`)、斜杠命令路由、写作 (`write-chapter.ts`)、审查 (`audit-chapter.ts`) 及自动模式 (`auto-mode.ts`) 的状态机流转。
- **上下文工程**：通过 `context-builder` 模块实现基于角色、伏笔和通用记录的语义召回 (`recall.ts`)，并组装包含硬约束连续性检查的 Prompt。
- **数据一致性**：引入 `BookRegistry` 管理数据库连接，配合 `snapshot-scheduler` 实现基于 WAL 备份的自动快照机制，确保写作过程中的数据安全。
