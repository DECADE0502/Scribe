后端用什么语言/栈写?

前端不用纠结(Vite + React 或 Vue 都行,后面再决定)。这题只问 server 那一侧。

A

TypeScript / Node.js(推荐)

核心理由:Vercel AI SDK 是当今最成熟的 AI 抽象层,在 Node 生态里。CharacterArc 用的就是它

能直接吃到:streamText / streamObject / tools / 自动 provider 兼容 / tool_use 降级 / Anthropic prompt cache

前后端同语言:类型可以共享,IDE 体验最好

缺点:依赖管理是 npm,要忍受 node_modules 巨大

B

Python(FastAPI / Litestar)

核心理由:AI 生态最丰富(LangChain / LlamaIndex / instructor / litellm),想接 RAG / embedding / 本地模型最方便

对个人项目友好:写脚本快,数据处理强

缺点:Vercel AI SDK 的 Python 等价物没那么成熟,要自己拼 OpenAI SDK + Anthropic SDK,多 provider 抽象要手写

C

Go(像 ainovel-cli)

核心理由:单二进制部署,性能好,你刚装过 Go

缺点:LLM 生态最弱,几乎所有 SDK 都是社区维护质量参差。想用 Vercel AI SDK 那种工具级抽象,得自己写

对这种"少量并发 + 大量 LLM 调用"的工作负载,Go 的强项(并发)用不上,弱项(SDK 生态)很疼
